AI Agent 核心觀念與教育行政實踐

從「問答聊天」到「自主代理」的典範轉移

AI 不再只是百科全書，
而是會主動做事的「數位教學夥伴」

過去我們習慣在 ChatGPT 對話框裡「打一句、回一句」，稍微換個話題它就忘了上文。現在的 AI Agent（智慧代理人） 能具備目標導向、拆解任務、自己查檔案、使用工具驗算、甚至自我檢查錯誤的閉環能力！

1. 感知環境
讀懂課綱、公文、學生成績表與作業細節
2. 自主推理
規劃步驟（先算質因數、再對照錯誤盲點）
3. 執行反思
調用工具計算、自我校對並交付成果

傳統聊天機器人 (Chatbot / LLM)

被動式問答・打一下動一下

  • 缺乏記憶連貫：開新對話就全忘了，無法記住 701 班這學期的常規進展或特定學生的輔導細節。
  • 無法調用真實工具：純靠文字預測，算複雜數學題目容易出現「幻覺」算錯，無法執行真實試算表。
  • 老師依舊是搬運工：每次都要重新複製貼上背景，再手動複製產出去排版，耗時耗力。
現場感受：「就像請了一個很博學的實習生，但每交辦一件事都要站在他身後一句一句盯著看。」

智慧代理人 (AI Agent)

目標驅動・具備自主行動與工具能力

  • 目標導向任務拆解：給予「依段考第 1 章錯題設計補救試卷」大目標，自動分步查課本、出題、驗算。
  • 真工具調用與驗證：自動執行代碼算式除錯、查詢最新教育局公文規章、匯出標準 Word/PDF。
  • 自我反思與糾錯（Reflection）：生成解答後主動驗算「答案是否合理？語氣是否符合親師倫理？」。
現場感受：「就像擁有一個專業副手，只要交待目標與規範，他會自己找資料、跑程序、檢查無誤後交差！」

Prompt vs. Skill vs. Project：核心三要素徹底辨析

老師們最常問：「我已經會下 Prompt 了，為什麼還要知道 Skill 和 Project？」

單次指令 📝

Prompt（提示詞）

口頭吩咐・便利貼上的交代

本質：你在當下對話框中輸入的單次文字指令。

生命週期：用完即丟，換一個視窗或明天重新打開就失效。

最大痛點：如果想維持品質，每次都要重新打一大串限制與格式，累積大量無效重複。

學校實例 「幫我把這段文字改成客氣一點的語氣發給家長。」
標準SOP ⚙️

Skill（技能模組）

專家工作法・隨調隨用的外掛能力

本質：將特定任務的專業步驟、檢查清單與輸出格式打包成的模組。

生命週期：常駐可用。AI 平時不佔用記憶，偵測到符合任務時自動載入（按需載入）。

核心威力：將資深優良教師的教學/行政心法 SOP 化，任何新進老師呼叫都能產出高水準成果。

學校實例 「親師衝突同理心溝通信生成 Skill」、「國中數學階梯式出題 Skill」
工作環境 📁

Project（專案空間）

作戰指揮室・專屬背景知識庫

本質：一個長期的工作區，常駐掛載特定文件庫（PDF/表格/規章）與專案守則。

生命週期：長期持續，貫穿一整個學期、學年或重大活動籌備期。

核心威力：AI 在這個專案內的所有回答，都自動「認識」該處室或該班級的背景脈絡，不用每次重說。

學校實例 「701 班班級經營專案（內建學生特質與家長筆記）」、「南一數學 1 上專案」
Antigravity & AI Agent 核心配置解密

設定了 Project，為什麼還要指定「工作資料夾 (Folder / Workspace)」？

💡 現場老師神比喻：Project 就像「任務團隊」，而 資料夾就像「開會的教室或會議室」！

👥

Project（專案）= 任務團隊

「我們是誰？我們的目標、規則與具備哪些技能？」

  • ● 無形的心智與靈魂：定義了 Agent 的角色指令（System Prompt）、目標、溝通語氣與指導方針。
  • ● 裝備與技能包（Skills）：規定了這個團隊配備了什麼法寶（例如：掛載「南一版國中數學階梯出題 Skill」、「親師三明治溝通 Skill」）。
  • ● 長期記憶（Memory）：累積該團隊特有的決策偏好與歷史經驗。
學校比喻：「國中數學段考命題小組」或「校慶運動會籌備委員會」。
🚪

Folder / Workspace = 會議室 / 實體場地

「團隊今天在哪裡集合？桌面上擺放著哪些具體檔案？」

  • ● 有形的物理空間與檔案庫：電腦硬碟中的具體路徑（例如：c:\...\國中數學1上課本_全六冊\）。
  • ● 操作視野與權限邊界：Agent 只能看見並直接讀寫「這間會議室」內的 PDF 課本、試題 Word 檔或公文資料。
  • ● 產出存放處：Agent 跑完驗算生成的練習卷或擬辦公文，會直接儲存在這個資料夾桌面上。
學校比喻：「第一會議室」、「教具與課本儲藏室」或「701 導師室」。

📍 第 1 次段考：把工作資料夾切換到 國中數學1上_第1章因數分解/ ➔ Agent 立刻讀取該章 PDF 並出題。

📍 第 2 次段考：團隊成員與守則完全不用重寫！只需把工作資料夾切換到 國中數學1上_第2章一元一次方程式/，命題小組立刻在新場地就位！

🏢 靈活性情境二

同一個會議室（Folder），借給不同團隊（Project）進駐

學校硬碟中有一個共同資料夾 114活動_校慶籌辦資料夾/，裡面堆滿活動企劃書、經費預算表與各班名冊。

👥 上午「學務處活動小組 Project」進駐：專注於讀取趣味競賽項目，產出賽程時間表與志工分工單。

💼 下午「總務處經費核銷 Project」進駐：換不同專案靈魂進來，專注於檢核帳篷租借單據金額是否符合主計上限。

為什麼指定資料夾是校園資安的第一道防線？（門禁卡哲學）

如果我們不指定資料夾，AI Agent 就等於拿著「全校萬用鑰匙」，可以在整台電腦硬碟中漫遊。這是極度危險的！

🛡️ 明確邊界（沙盒保護）

指定資料夾如同給 Agent 一張「僅限進入 701 會議室」的門禁卡，它的眼睛與雙手只能觸碰指定資料，絕不會越界。

🔒 保護個資與機密

避免 Agent 在搜尋時誤觸隔壁資料夾的「教職員人事考績」或「全校特教生鑑定病歷」，完全合乎個資保護法規。

⚡ 避免干擾與省運算

不需要讓 Agent 在幾萬個檔案裡大海撈針，專注在指定資料夾的 5 個檔案，反應更精準、速度快十倍！

國中數學專業備課：南一版 1 上「因數分解與負數運算」精準落地

國中數學最大的難題在於「雙峰現象極度嚴重」與「死記口訣導致概念混淆」。AI Agent 能扮演「資深命題委員 + 錯因診斷醫生」，讓分層出題與概念補救不再需要耗費一整晚！

1

認知鷹架三階階梯出題

教材對照：南一第 1 章第 2 節「質因數分解與最大公因數」。
Agent 流程：自動生成【A 級基礎短除法計算】➔【B 級標準分解式指數取法】➔【C 級生活應用排隊切分題】，每題自帶逐步引導鷹架。

2

學生錯因自動診斷與微補救

常見痛點：學生寫 \( \text{GCD}(72, 108) = 216 \)，死背口訣卻不知因數不能大於原數。
Agent 流程：Agent 辨識出迷思概念（將 GCD 次方與 LCM 次方搞混），自動生成蘇格拉底式提問與 1 題同質微補救單。

3

代碼驗算與排版自動化（Tool Calling）

避免幻覺：傳統 AI 常常在生成素養題時把數字出成無解或分數非整數。
Agent 流程：Agent 自行調用 Python 解題驗算，確保題目數字整除且無邏輯瑕疵，並自動轉為 LaTeX 或 Word 格式。

實戰對比：南一 1 上數學錯題 10 秒生成精準補救

❌ 過去做法（傳統死背或重複寫大卷）

發一張 20 題的考卷叫學生重寫，學生因為不懂原理只覺得被懲罰，依然在 GCD 與 LCM 的指數挑選上亂猜，雙峰差距持續擴大。

✔ Agent 賦能做法（概念深究）

Agent 自動提問：「216 可以整除 72 嗎？既然是要『共同因數』，能比原本的數字還大嗎？」一秒擊中概念核心，再配 1 題自檢題即完成補救。

專業名詞大解鎖：不再被科技火星話困擾

從 AGI 到 MCP，用教育工作者最容易理解的白話全盤梳理

終極願景 Artificial General Intelligence

AGI (通用人工智慧)

具備與人類相當甚至超越人類的廣泛認知能力，能在各種未見過的新環境中自主學習、推理與解決問題的終極 AI。相對於過去只能下圍棋的 Narrow AI，未來的 AGI 能像資深校長般綜合統籌各類學科與校務！

💡 關鍵連結：AI Agent 被公認為當前通往 AGI 最關鍵的一躍！
核心基石 Large Language Model

LLM vs. AI Agent

LLM 是「大腦」，擅長理解語言與推測字詞；AI Agent 是「完整的人」，擁有了大腦（LLM）、眼睛（感知輸入）、手腳（工具調用 API）與筆記本（長期記憶與外部資料夾）。

💡 譬喻：LLM 是裝滿知識的腦神經，Agent 是走到操場執行的體育老師。
最新架構標準 Model Context Protocol

MCP (模型上下文協議)

由 Anthropic 推出的開放通訊協定，如同「AI 界的 Type-C 通用插座」。讓不同的 AI 代理人可以安全且標準化地插拔學校的 Google 雲端硬碟、資料庫、本機文件夾與特殊教學工具。

💡 優勢：不用再為每個校務系統個別寫客製連接程式。
團隊協作 Multi-Agent System

Multi-Agent (多代理人協作)

由多個各自扮演專業角色的 Agent 組成的團隊。例如出段考試卷：出題 Agent 負責出題 ➔ 驗算 Agent 負責跑代碼解題並檢查答案 ➔ 排版 Agent 轉成雙欄試卷。

💡 核心精神：分工合作比讓單一 AI 做所有事情穩定度高出十倍！
行動能力 Function Calling

Tool Calling (工具調用)

AI 發現自己光靠推理可能算錯或資料不足時，主動發起呼叫外部程式的行為。例如呼叫「Python 解題環境」算因數、呼叫「Google 搜尋」查最新教育法規、呼叫「檔案讀取器」開公文。

💡 徹底解決：徹底根除大語言模型算數容易算錯與幻覺的問題。
安全防線 Human-in-the-Loop

Human-in-the-Loop (人在迴圈中)

雖然 Agent 具備高自主性，但在關鍵節點（如：成績定稿、公文正式核章送出、牽涉學生輔導隱私的敏感親師信發布），必須由真實人類教師/行政主管親自核准。

💡 教育核心：AI 是最強副駕駛，老師才是掌握方向盤與溫度的機長。
