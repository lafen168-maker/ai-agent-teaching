## 💡 一、 觀念革命：什麼是 AI Agent（智慧代理人）？

### 1. 從「聊天機器人 (Chatbot)」到「智慧代理人 (AI Agent)」的典範轉移

許多老師過去使用 ChatGPT、Claude 或 Gemini 時，感受常停留在：
* **「我問一句，它答一句」**：需要老師像擠牙膏一樣不斷下指令。
* **「換個視窗就失憶」**：每次都要把 701 班有哪些特教生、哪些家長比較敏感從頭重新說一次。
* **「經常算錯或出幻覺」**：請它出數學因數分解或最大公因數題目，偶爾會給出不能整除或數字矛盾的算式。

**AI Agent（智慧代理人）** 則是生成式 AI 的第二波進化：
它不再只是一個被動回答問題的百科全書，而是一個**「以目標為導向（Goal-Driven）、具備自主行動力與工具使用能力的數位協作夥伴」**。

### 2. AI Agent 的五大核心運作要素

```
┌────────────────────────────────────────────────────────┐
│                   AI Agent 運作體系                     │
├───────────────┬────────────────────────┬───────────────┤
│  👀 感知輸入   │      🧠 大腦與規劃      │   🛠️ 工具行動   │
│ (Perception)  │  (LLM Reasoning & CoT) │  (Tool Use)   │
│ 課本PDF/公文/ │  任務拆解、推理思考鏈   │ Python代碼驗算│
│ 學生作業/成績 │                        │ 讀寫Word/搜尋 │
├───────────────┴────────────────────────┴───────────────┤
│  💾 記憶機制 (Memory)  │   🛡️ 反思評估 (Reflection)    │
│  短期上下文 + 長期專案知識庫 │   交卷前自我校驗、格式與語氣糾錯 │
└────────────────────────────────────────────────────────┘
```

1. **感知環境 (Perception)**：接收外部多元訊號，包括讀入南一國中數學課本目錄 PDF、教育局長篇公文掃描檔、學生成績 Excel 試算表。
2. **規劃與推理 (Planning & Reasoning)**：利用思維鏈（Chain of Thought, CoT）與 ReAct 邏輯，主動將大目標分解為「第一步做什麼、第二步調用什麼資料、第三步如何整合」。
3. **記憶機制 (Memory)**：
   * **短期記憶**：維持本次對話的邏輯連貫。
   * **長期記憶**：透過專案資料庫（RAG 技術），永遠牢記該班級的學生特質、歷次輔導紀錄與學校慣用簽呈格式。
4. **工具調用 (Tool Calling / Function Calling)**：跳出文字框限制，主動調用真實世界的軟體工具（如呼叫 Python 直譯器驗算因數、連線搜尋引擎查最新法規、匯出 Word 試卷）。
5. **反思與評估 (Reflection)**：在將成果交付給老師之前，自己先當自己的考官。「這題的解答算對了嗎？」「這封信的語氣是否容易讓家長感到被責怪？」發現問題自主修正後再交差。

## ⚖️ 二、 核心三要素辨析：Prompt vs. Skill vs. Project

現場教師與行政同仁最常感到混淆的概念：

| 維度 | Prompt（提示詞） | Skill（技能模組） | Project（專案空間） |
| :--- | :--- | :--- | :--- |
| **一句話定位** | 單次任務的即時指令 | 封裝好的專家 SOP 工作法 | 長期持有的作戰指揮室與資料庫 |
| **生命週期** | **用完即丟**（隨打隨用） | **常駐調用**（跨任務共用） | **持續一學期或一學年** |
| **內含元件** | 文字問題或單一要求 | 角色定義、檢查清單、好壞範例、執行腳本 | 歷史公文庫、課本 PDF、班級名冊、專案設定 |
| **最大痛點/價值** | 每次都要重新交待背景與限制 | 按需載入，大幅提升產出穩定度 | 讓 AI 擁有專屬脈絡，成為班級/處室專用秘書 |

### 🌟 兩大直覺比喻（演講時強力推薦使用）：

#### 🍳 譬喻一：米其林廚房
* **Prompt**：客人點單時的便利貼備註——*「這碗牛肉麵少放鹽、不要加酸菜」*（吃完便利貼就丟進垃圾桶）。
* **Skill**：主廚傳承的精確 SOP 食譜——*「紅燒牛肉麵秘傳 SOP」*（精確規定牛腱熬煮幾分鐘、香料克數、下麵秒數，任何學徒只要照著做就能維持米其林水準）。
* **Project**：整間旗艦餐廳——包含冷藏庫裡的新鮮食材、進貨廠商名冊、廚房設備與過去半年的營運報表。
* **AI Agent**：那位**自主能幹的副主廚**——看到客人點餐，自己翻開食譜（Skill）、開冰箱拿肉（Project）、開火煮麵、出餐前試喝一口確認鹹淡（Reflection），有瑕疵立刻重做！

#### 🏫 譬喻二：學校行政辦公室
* **Prompt**：主任走過走廊口頭吩咐——*「幫我查一下教育部那份公文補助多少錢」*。
* **Skill**：學務處制定的——*「校外教學標準作業查檢表與簽呈範本」*。
* **Project**：*「114學年度畢業旅行專案資料庫」*（包含廠商標案合約、全校學生遊覽車座位表、家長回條紀錄）。
* **AI Agent**：那位**能獨當一面的行政幹事**——收到畢旅目標，自己調資料、算預算、檢查保險法規，最後列印出漂亮公文請主任核章。

### 🏢 進階觀念解密：在 Antigravity 中，為什麼設定 Project 還要指定「工作資料夾（Folder / Workspace）」？

很多老師在接觸 Antigravity 或進階 AI Agent 系統時常好奇：「我明明已經建立了 Project，為什麼系統還要我指定一個電腦資料夾？」

#### 💡 老師的神級譬喻：
* **Project（專案）＝ 任務團隊 / 專案小組**（例如：南一數學段考命題小組、校慶籌委會）
* **Folder / Workspace（工作資料夾）＝ 實體開會的教室或會議室**（例如：第一會議室、教具儲藏室、701 教室）

```
┌────────────────────────────────────────────────────────┐
│           Project（專案）= 任務團隊的心智與靈魂          │
│   • 定義「我們是誰？目標是什麼？遵循什麼規範？」           │
│   • 系統提示詞（System Prompt / Rules）               │
│   • 掛載專業技能包（Skills）：如因數分解出題、公文簽呈   │
│   • 專屬長期記憶（Memory）                             │
└──────────────────────────┬─────────────────────────────┘
                           │ 進入實體場地開會
                           ▼
┌────────────────────────────────────────────────────────┐
│    Folder / Workspace（工作資料夾）= 開會的教室與會議室 │
│   • 定義「團隊今天在哪裡集合？桌面上擺放著哪些具體檔案？」│
│   • 電腦硬碟中的具體路徑（如 c:\...\國中數學1上課本\） │
│   • Agent 獲得對該資料夾的讀寫視野與操作邊界           │
│   • 生成的成果（Word試卷、簽呈草稿）直接存放在此       │
└────────────────────────────────────────────────────────┘
```

#### 🌟 這種架構為教育現場帶來的兩大超強靈活性：

1. **同一個團隊（Project），可以換到不同會議室（Folder）開會**：
   * 您建立好一個「國中數學命題小組 Project」（已內建南一版命題鷹架與防呆驗算 Skill）。
   * 第一次段考：把工作資料夾指定到 `國中數學1上_第1章因數分解/` ➔ Agent 自動抓取第 1 章內容開始出題。
   * 第二次段考：團隊設定完全不用重寫！只需把工作資料夾換成 `國中數學1上_第2章一元一次方程式/`，同一個專業命題團隊立刻在新場地就位出題！
2. **同一個會議室（Folder），可以借給不同團隊（Project）輪流進駐**：
   * 學校硬碟中有一個共用資料夾 `114活動_校慶資料夾/`（放滿全校報名表與經費預算表）。
   * 上午：由「學務處活動小組 Project」進駐該資料夾，負責排定競賽時程表。
   * 下午：由「總務處主計 Project」進駐同一個資料夾，負責審查帳篷租借單據是否符合主計上限。
3. **校園門禁與資安保護（沙盒邊界）**：
   * 指定資料夾等於給 Agent 一張「專屬門禁卡」。Agent 只能在指派的會議室內翻閱檔案，**絕不能任意推開隔壁「人事室（教職員考績）」或「註冊組（全校學生個資）」的大門**，徹底確保校園資安合規。

## 📖 三、 關鍵術語大解鎖與 AGI 演進

1. **LLM（大語言模型，Large Language Model）**：
   * 如 GPT-4、Claude 3.5、Gemini 1.5 等。LLM 就像一個**極具智慧的「大腦」**，擅長語言理解與接龍，但缺乏手腳，無法直接操作電腦系統。
2. **AI Agent（智慧代理人）**：
   * 在 LLM「大腦」之上，賦予了「感知眼睛」、「工具雙手」與「長期記憶筆記本」，形成具有自主行動能力的完整個體。
3. **AGI（通用人工智慧，Artificial General Intelligence）**：
   * 具備與人類相當甚至超越人類心智的廣泛認知能力，能在**未見過的新情境**中自主學習與解決問題。
   * **關鍵連結**：過去的 AI 是只能做單一任務的 Narrow AI（如專門辨識人臉或下圍棋）；當前從 LLM 走向 Agentic AI，正是科技界公認通往 AGI 最關鍵的一座跨海大橋！
4. **Tool Calling / Function Calling（工具調用）**：
   * AI 主動判斷文字推理不足時，呼叫外部工具（如計算機、Python 程式碼、SQL 資料庫、Web 搜尋）以獲取精確真實結果的能力。
5. **MCP（模型上下文協議，Model Context Protocol）**：
   * 由 Anthropic 發起的開放標準協議，如同「AI 界的 Type-C 插座」。讓不同廠牌的 Agent 能透過統一標準插拔學校的 Google 雲端、本機硬碟與校務系統。
6. **Multi-Agent（多代理人協作系統）**：
   * 類似學校處室分工，由多個各司其職的 Agent 協同合作。例如：出題 Agent ➔ 驗算 Agent ➔ 排版美編 Agent。
7. **Human-in-the-Loop（人在迴圈中）**：
   * 在涉及教育倫理、成績核定、正式公文發文與敏感親師通訊時，**必須由人類教師或主管擔任最終把關與決策者**。

## 🏫 四、 三大落地實戰情境詳解

### 情境一：教師班級經營篇（親師溝通與常規輔導）

#### 現場痛點：
* 處理學生衝突與違規事件時，導師在電話或聯絡簿直接陳述，常因語氣生硬引發家長防衛與投訴。
* 學生平時晤談紀錄分散，期末撰寫輔導 B 表或轉介資料時痛苦不堪。

#### Agent 解決方案：
* **掛載【親師同理心溝通三明治 Skill】**：
  * **第一層（肯定）**：認可孩子在校的優勢特質（如熱愛運動、富正義感）。
  * **第二層（客觀事實）**：以非暴力溝通語言還原事件過程，並陳述孩子向老師表達的受挫心境。
  * **第三層（行動與處置）**：說明校方當下的保護處置與學生的反思和解。
  * **第四層（邀約合作）**：以教育夥伴立場邀請家長共同引導，附上溫暖關懷。

---

### 情境二：國中數學教學專業篇（南一版 1 上教材案例）

#### 現場痛點：
* 國一上學期第一章「因數分解與分數運算」，學生程度兩極化。
* 學生常死背口訣，寫出 $\text{GCD}(72, 108) = 216$ 這種「公因數居然比原數大」的迷思概念（Misconception），卻不知問題出在將 GCD 與 LCM 的指數選取規則搞反。
* 傳統 AI 出題常出現無法整除或分數極其難看的瑕疵題目。

#### Agent 解決方案：
* **掛載【南一 1 上數學階梯出題與錯因診斷 Skill】**：
  1. **認知鷹架三階出題**：自動產出「A 級短除法基礎題」、「B 級指數選取概念題」、「C 級生活情境素養題（如分裝水果籃）」。
  2. **錯因自動歸因**：辨識學生作答是「短除法除錯」還是「指數規則顛倒」，給予蘇格拉底式引導提問（*「想一想，72 的因數有可能比 72 還大嗎？」*）。
  3. **Python 工具雙重驗算**：Agent 在背景調用程式解題，確認標準分解式正確無誤才輸出，徹底消除計算幻覺。

---

### 情境三：學校行政工作篇（公文速讀、活動管考與核銷）

#### 現場痛點：
* 教育局實施計畫動輒 15~20 頁，繁文縟節耗費行政同仁大量閱讀時間。
* 新任行政組長不熟悉正式公文「主旨、說明、擬辦」的標準法規格式。
* 主計法規繁雜，講座鐘點費、差旅費或設備採購額度一旦算錯便會遭退件重簽。

#### Agent 解決方案：
* **掛載【學校公文速讀與簽呈擬辦 Skill】**：
  1. 上傳公文 PDF，10 秒萃取「發文字號、主旨、補助額度（經常門/資本門）、承辦截止日、會辦處室」。
  2. 自動輸出符合學校行政規範的「標準三段式擬辦簽呈草案」。
  3. 對照縣市主計基準，自動檢驗預算表單價是否超標。

## 🚀 五、 教學與行政人員起步三步驟

1. **第 1 步：盤點時間黑洞**  
   找出你每週最繁瑣、高重複性且有固定規則的工作（如每週生活常規週報、段考前出小考卷、教育局補助公文簽呈）。
2. **第 2 步：將你的專業寫成第一個 Skill**  
   不要只依賴單次 Prompt。將你的專業心法、檢查清單、好範例寫成一個 Markdown 規範檔（如 `Parent-Communication-SOP.md`），隨時可以重複掛載。
3. **第 3 步：搭建處室/班級專屬 Project**  
   在支援 Project 的 AI 平臺中建立資料庫，丟入「南一數學課本 PDF」、「學校行事曆」、「歷年公文範本」，讓 AI 成為最懂你們學校的專屬數位分身！

## 🛡️ 六、 人在迴圈中（Human-in-the-Loop）：教育的核心價值

在全面導入 AI Agent 的時代，請永遠牢記：
> **「AI Agent 是效能極高的超級副駕駛，但教育的機長永遠是具備同理心與教育愛的現場老師！」**

* **嚴守資安與隱私**：涉及學生真實個資（身分證字號、家庭敏感隱私），務必去識別化後再行諮詢。
* **堅持最終審查權**：不論是給家長的一封信、考卷的題目與答案、還是呈給校長的正式公文，都必須經過教育工作者的專業眼睛審核核可。
* **科技讓行政減量，是為了把時間還給教育最核心的靈魂——陪伴每一個孩子！**
